# urban_heat_island_3D_CA
Python simulation of heat transfer in urban heat island with 3D cellular automata. Von Neumann neighbourhood is applied.
# Creation and purpose
The code was co-created in twelve iterations between author and Sonet 4.6 model in June 2026. It is a part of experiment described in https://doi.org/10.18690/um.fov.5.2026.8
